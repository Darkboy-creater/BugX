> Advanced Pentesting Framework for Termux - Built from Scratch

## Features

| Module | Description |
|--------|-------------|
| Port Scanner | Multi-threaded Nmap-style scanner |
| Payload Generator | 12+ reverse shell payloads |
| Multi Handler | Multi-client session manager |
| SQL Scanner | Error Boolean Time-based SQLi |
| XSS Scanner | Reflected XSS detector |
| Subdomain Finder | DNS brute force |
| Admin Finder | 500+ admin paths |
| Dir Bruteforcer | Hidden files and dirs |
| Header Checker | Security headers analyzer |
